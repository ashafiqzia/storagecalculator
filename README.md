# Storage Unit Converter



## Purpose

This is my first Python project. It converts storage from GB to MB and KB.



## How to Run

1\. Install Python.

2\. Save the code as `storage.py`.

3\. Run the program and enter storage in GB.



## Example Input/Output



Input:

Enter storage in GB: 2



Output:

Storage in MB: 2048.0

Storage in KB: 2097152.0
